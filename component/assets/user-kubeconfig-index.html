First time setup

  1. Make sure you have a recent kubectl installed. See the upstream docs for install instructions.
  2. Download the kubectl kubelogin plugin and ensure it’s available in your $PATH as kubectl-oidc_login
  3. Verify that the plugin is available.
    kubectl oidc-login --version
  4. Download this cluster’s kubeconfig
  5. Set the $KUBECONFIG environment variable
    export KUBECONFIG=~/Downloads/{{ env "CLUSTER_NAME" }}.kubeconfig
  6. Test access
    kubectl auth whoami
    If everything is setup correctly, this should authenticate you with your VSHN account in your browser and then show some details about your user.
